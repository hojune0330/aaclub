# AAC Club Archive

AAC Club의 계약 문서, 선수 안내물, 브랜드·문서 디자인 자산을 변경 단위별 Pull Request로 보관하는 비공개 저장소입니다.

이 저장소의 자료는 계약 검토 및 내부 운영을 위한 것입니다. 외부 공개·배포 전에는 개인정보, 계약 조건, 초상·상표 사용 권한을 다시 확인해야 합니다.

## 운영 원칙

- 확정 산출물과 참고 원본을 분리합니다.
- 폐기본과 중간 렌더링은 원칙적으로 보관하지 않습니다.
- 변경 묶음마다 별도 브랜치와 초안 PR을 사용합니다.
- HWP, DOCX, PDF, ZIP, PNG는 바이너리 자료로 취급합니다.
- 자료는 날짜별 스냅샷 폴더(`archive/YYYY-MM-DD/`)로 보관합니다.
- 이전 스냅샷과 내용이 동일한 파일은 중복 보관하지 않습니다.
- 파일명은 NFC(완성형)로 정규화합니다.
