## 1. 톤 & 무드 원칙

브랜드 시스템의 "Editorial × Sports Club 80/20" 원칙과 톤을 맞춥니다.

| 축 | 지침 |
|---|---|
| **컬러 톤** | Warm · natural · 필름 그레인 살짝. 채도 낮게. **오프-화이트 페이퍼 배경과 자연스레 붙는 색감**. |
| **라이팅** | 하드 라이트 지양. 자연광 or 큰 소프트박스. 그림자는 부드럽지만 **콘트라스트는 살아있게**. |
| **움직임** | Motion-blurred OK — 오히려 좋음. 스톱-액션보다는 **시간의 층위가 보이는 프레임** 선호. |
| **표정** | 미소 X, 카메라 눈맞춤 X 원칙. 훈련 몰입·회복 중·정면 응시 등 **조용한 상태**. |
| **후반보정** | 채도 -10 ~ -15. 하이라이트 살짝 눌러 매트하게. **그레인 미세하게 (film 400 정도)**. |
| **금지** | 화려한 그라디언트 필터, 비니에트, 컬러 룩업(오렌지/틸 대비), 뷰티 리터치, 인스타그램 프리셋. |

**참고 무드**: The Gentlewoman, Cereal Magazine, POPEYE, Nike '80s Runner's World 광고, 무라카미 하루키 『달리기를 말할 때 내가 하고 싶은 이야기』 표지 톤.

## 3. 촬영 사양 (공통)

| 항목 | 스펙 |
|---|---|
| **파일** | RAW + JPEG. 셀렉트 후 JPEG만 리포에 |
| **해상도** | 최소 2000px 짧은 변 (인쇄 대비 여유) |
| **컬러 스페이스** | sRGB (웹·PDF 공통) |
| **파일명** | `{ISO date}_{athlete-slug}_{scene}_{seq}.jpg`<br/>예: `20260920_jang-hojune_portrait_01.jpg` |
| **화이트 밸런스** | 5200–5600K (약간 웜) |
| **노출** | 하이라이트 클립 절대 금지. 새도우 디테일 살릴 것 |

## 4. 셀렉트 원칙 (촬영 후)

컷당 3~5장으로 좁혀서 주세요. 저는 아래 기준으로 골라요:

1. **"저 선수가 자기 훈련에 몰입한 순간인가"** — 표정/자세로 판단
2. **"카메라를 의식하지 않은가"** — 어색한 포즈, 억지 미소는 탈락
3. **"이 브랜드의 조용한 톤과 맞는가"** — 과한 하이라이트·특수 필터 탈락
4. **"프린트에서 읽히는가"** — 언더 노출, 세부 뭉개짐 탈락

## 5. 저장 위치 & 규칙

```
assets/photos/
├── athletes/                       ← 선수별 초상 (P0-1)
│   ├── 20260920_jang-hojune_portrait_01.jpg
│   ├── 20260920_lee-seobin_portrait_01.jpg
│   └── ...
├── training/                       ← 훈련·트랙 (P0-2, P0-3, P1-3, P1-6, P1-7)
├── still-life/                     ← 정물 (P1-4, P1-5, P1-8)
└── seasonal/                       ← P2
```

- **RAW는 여기에 커밋하지 마세요** (용량). 별도 드라이브에 보관.
- 저용량 웹용 JPEG(1600px 짧은 변)만 리포에 넣는 것 권장.
- 초상권·모델 릴리스 사인은 별도 폴더 `contracts/photo-release/`에 관리.
