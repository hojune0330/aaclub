# UI Kit — Brand System (Mood 04 Hybrid)

Mood 04 (Editorial × Sports Club Hybrid) 브랜드 시스템의 조합 보드.
`index.html`을 열면 커버 · 컬러 · 4 필러 · 타이포 · 애플리케이션이 한 페이지에 스크롤로 나옴.

## Components
- `ColorBoard.jsx` — 팔레트 스와치 + 55/25/12/8 사용 비율 바
- `PillarsBoard.jsx` — 4 Pillars 아이콘 카드 + 타이포 3열 (Display · Eyebrow · Body)
- `ApplicationsBoard.jsx` — 시즌 포스터, 명함 앞뒷면, 배번, Instagram, 훈련 노트
