# AAC Editorial Document Design

Create official AAC communication with quiet editorial hierarchy, exact Korean text, and print-grade legibility.

## Required inputs

1. Read the complete source document and preserve every amount, deadline, condition, exception, and qualifier selected for the summary.
2. Read [references/design-system.md](references/design-system.md) before designing.
3. Use the supplied wordmarks from `assets/` without redrawing them.

## Workflow

1. Reduce the source to the minimum decision-useful content. Keep legal detail in the source document, not in the visual.
2. Choose A4 portrait for official guides and handouts. Use a 4:5 crop only when the user explicitly needs an Instagram carousel.
3. Draft a hierarchy before styling: metadata, title, one-sentence rule, primary table, procedure, exceptions, source note.
4. Build with live text in HTML/SVG or a document tool. Do not ask an image model to render Korean copy.
5. Render PNG and PDF when practical. Inspect every page at full size for glyph errors, clipping, weak contrast, cramped rows, and awkward page breaks.
6. Compare the finished surface against the reference rules. Revise until it reads as an official AAC document.

## Non-negotiable visual rules

- Prefer warm off-white paper, charcoal ink, hairline rules, and one restrained teal accent.
- Use serif only for the main editorial statement; use Korean sans-serif for all operational content and mono for metadata or figures.
- Use open page geometry, asymmetric editorial grids, and horizontal rules. Avoid rounded cards, neon colors, oversized poster lettering, stickers, emoji, decorative icons, gradients, and social-ad styling.
- Keep tables flat and document-like: aligned columns, quiet header band, horizontal separators, tabular figures, and generous row padding.
- Set Korean body copy large enough to read on a phone after export. Never shrink text to force a one-page result; split pages instead.
- Apply the AAC wordmark once per page at a restrained size.

## Content rules

- Distinguish the general rule from company-approved exceptions.
- Show monetary amounts and deadlines as scan targets.
- State limits near the corresponding benefit, not in detached fine print.
- Use neutral, factual Korean. Avoid sales slogans, exclamation marks, and exaggerated claims.
- Add a short source/precedence note when the visual summarizes a contract or operating standard.

## Delivery checklist

- Text matches the source exactly.
- No information is implied that the source does not authorize.
- All pages share one grid and token set.
- PNG dimensions are consistent across a series.
- PDF and PNG render the same content.
- The result still looks like a document when printed in grayscale.
